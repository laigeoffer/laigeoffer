你好，欢迎来到《如何将 PmHub 写入简历》篇！

现在找工作特别是秋招，最重要的永远在简历上，而简历中，HR 或者面试官最看重之一就是项目经历了，其他的如专业技能，只要你不瞎写，其实都大差不差。

如今市场情况对初级程序员的需求没那么多了，你会发现，投简历越来越难，明明优化了好几遍，但总是石沉大海，抛去别的不说，主要原因还是市场供需关系决定的。前些年计算机火的不行，在互联网的鼓吹之下，我相信一堆的同学跟风报了计算机专业，但好景不长，等轮到自己毕业却发现，找工作突然变得如此艰难。

企业现在业务也严重缩水，过去只要有好的 idea，光平一个 PPT，一个原型就可以忽悠来融资，然后招聘大量的开发来搞，但现在需求变少了，融资困难了，业务自然也就少了，对程序员特别是初级程序员的需求就没那么多了。

我想先跟你分享一下实际情况，所以我们一定要想办法应对，虽说对初级程序员的需求变少了，但好在前些年还是做了不少系统，这些系统也是需要人维护和迭代升级的，同样也是有需求在的。

所以，我建议是，校招生一定要摆正心态，告诉企业，你已不再是初级程序员，你同样能干别人能干的活，而且招你还比招社会上那些有经验的更便宜，性价比拉满，还可以给企业带来补贴，企业自然而然争抢着要你的。

那如何表现呢？最重要的还是在简历，在简历中的项目上下功夫，不要再整烂大街的项目了，一看就是在 B 站上学习的，很可能都过不了第一关——简历筛选。

## 项目介绍

- 精简版

- 详细版

:::

## 主要工作
可以根据自己对项目的理解掌握程度，选 6 个左右去写并适当调整文案，灵活一些，增加一些区分度！

- 自定义 SpringCloud Gateway **全局过滤器**，实现自定义网关统一鉴权，统计**接口调用耗时**情况。
- 通过结合 Redis和 Lua 脚本，实现了基于计算器算法的**限流**方式。
- 将项目和任务审批流消息放入 Rocketmq，实现消息的**异步解耦**，提升系统效率和服务稳定性。
- 使用 Skywalking 实现了对 PmHub 的性能监控和分布式追踪，集成钉钉、邮件等通知渠道，使系统的整体响应时间降低了约30%，确保了系统运行的高可靠性和可维护性。
- 通过 OpenFeign和 Sentinel 集成实现自定义 fallback **服务降级**，减轻服务负担。Sentinel 和 Gateway 集成实现网关限流。
- 使用 Redis **分布式锁**，确保流程状态更新按顺序执行且不被其他操作干扰，保护流程状态的更新过程。
- 为保证任务审批状态的一致性，采用 Seata **分布式事务的 AT 模式**
- **自定义注解**加 **AOP** 实现服务接口鉴权和内部认证
- 通过采用 Cache Aside 模式，确保数据库更新后及时失效相关缓存，保证数据库和缓存的一致性。
- 基于 TransmittableThreadLocal (TTL) 自定义请求头拦截器，将Header 数据封装到线程变量中方便获取，减少用户信息数据库查询次数，同时验证当前用户有效期自动刷新有效期。
- 使用 **Docker Compose **搭建项目环境，简化项目部署过程，降低环境差异性问题，提升资源隔离安全性
