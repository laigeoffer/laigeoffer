## 专业技能撰写建议

先来看专业技能的撰写建议：

1、熟悉 Java 特性，如集合类、自定义注解、异常处理
2、熟悉计算机网络基础知识，如 OSI 七层模型，了解 TCP/IP、HTTP 协议
3、熟悉 synchronized、线程池、TransmittableThreadLocal 等实现原理
4、熟练掌握 MySQL，深刻理解事务 ACID 特性、索引、MVCC、以及日志等
5、熟练 Redis 的使用，对其持久化机制、内存淘汰策略有较深理解
6、熟悉 Rocketmq 消息队列，有过手动消息确认、应用解耦、消息消费的实战
7、熟悉 Docker 及 Docker Compose，并能独立部署上线
8、熟练掌握 JVM 内存机构、常见 GC 算法、双亲委派机制、类加载机制等
9、熟悉微服务架构，对主流技术栈如 SpringCloud、SpringCloud Alibaba 了解，有独立搭建微服务系统以及单体项目微服务化实战经验。

### 精简版项目介绍

简单直接，突出项目亮点，介绍核心业务，适合一页简历的球友。

:::info

基于 SpringCloud + SpringCloud Alibaba + flowable + Vue 的智能项目管理系统，用户可创建项目、指派任务、workflow 流程流转，还可以分配角色进行权限管控，关联审批流，做到项目的自动流程化管理。

:::

### 详细版项目介绍

把核心亮点前置，适当补充项目介绍，适合两页简历及以上的球友。

:::info

基于 SpringCloud + SpringCloud Alibaba + flowable + TTL + Vue 的一套智能项目管理系统，支持项目管理者自定义项目、发布上线项目，并指派任务给任务执行者，支持自定义流程、链接企微通知，管理者还能通过 ECharts 图标实时查看项目和任务进度，真正做到了项目管理的流程化和智能化管控。

:::

### 主要工作

可以根据自己对项目的掌握程度，选 6 个左右去写，记得适当调整文案，不要直接抄哦，灵活一些（让 GPT4 帮你润一手），增加一些区分度！

并且，要真正地掌握，别面试官一问就懵逼，就很尴尬，到时候面评很差，影响下一次的简历投递。最起码要把《[PmHub 教程中的面试系列](https://laigeoffer.cn/pmhub/learn.html)》完整地阅读两遍到三遍。

![PmHub 付费教程](https://cdn.tobebetterjavaer.com/stutymore/write-to-resume-20240809171449.png)

好，来看具体的写法：

- 自定义 SpringCloud Gateway 全局过滤器，实现网关统一鉴权，并统计接口调用的耗时情况。
- 结合 Redis 和 Lua 脚本，实现了基于计数器算法的限流方式，有效防止了流量突发导致的系统崩溃。
- 将项目和任务审批流消息放入 RocketMQ，实现消息的异步解耦，系统处理效率提升了约 20%。
- 使用 Skywalking 对 PmHub 进行性能监控和分布式追踪，并集成钉钉和邮件通知渠道，使系统的整体响应时间降低了约 30%。
- 通过 OpenFeign + Sentinel 实现自定义 fallback 服务降级，以减轻服务负担；并集成 Sentinel 和 Gateway 实现网关限流，防止服务过载。
- 使用 Redis 分布式锁，确保流程状态更新按顺序执行，避免其他操作的干扰。
- 为保证任务审批状态的一致性，采用 Seata 分布式事务的 AT 模式，有效避免了跨服务事务不一致的问题。
- 通过自定义注解+ AOP，实现服务接口鉴权和内部认证。
- 采用 Cache Aside 模式，确保数据库更新后及时失效相关缓存，保证数据库与缓存的数据一致性。
- 基于 TransmittableThreadLocal (TTL) 自定义请求头拦截器，将 Header 数据封装到线程变量中，减少了约 40% 的用户信息数据库查询次数，并自动刷新用户有效期。
- 使用 Docker Compose 搭建项目环境，简化项目的部署过程，减少环境差异性问题，提升资源隔离的安全性。
